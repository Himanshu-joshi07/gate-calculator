Calculator Instructions

Performs basic and advanced mathematical operations such as modulus, square root, cube root, trigonometric, exponential, logarithmic and hyperbolic functions, etc.
Operate the calculator with your mouse, using the buttons on screen.

Do's:

  • Press [C] before starting a new calculation.
  • Enter an equation using parentheses along with the other mathematical operators.
  • Use the built-in operations such as p (Pi), log and Exp to save time during a calculation.
  • Use the memory keys to build up cumulative totals. [M+]: Adds the displayed value to memory. [MR]: Recalls the value held in memory. [M-]: Subtracts the displayed value from memory.
  • Choose the angle unit (Deg or Rad) before beginning any calculation. Note: By default the angle unit is set to Degree

Dont's:

  • Perform several operations together.
  • Leave parentheses unbalanced.
  • Change the angle unit (Deg or Rad) part-way through a calculation.

Limitations:

  • Keyboard operation is disabled.
  • The output for a Factorial calculation is precise up to 14 digits.
  • The output for Logarithmic and Hyperbolic calculations is precise up to 5 digits.
  • Modulus (mod) performed on decimal numbers with 15 digits would not be precise.   Use mod only where the number has fewer than 15 digits — it gives its best results on smaller numbers.
  • The range of value supported by the calculator is 10(-323) to 10(308).
